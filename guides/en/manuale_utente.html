0. Development install (Mac)

Recommended project folder: KINEVA (not Stride / MOVEFitness). The same script also renames Stride_Policy → KINEVA-FIT_Policy, Stride_LandingPage → KINEVA-FIT_LandingPage, and Stride_Backups → KINEVA-FIT_Backups under ~/Documents: ./tool/rename_mac_project_dir.sh.

Device/simulator build: ./fit.sh (or ./KINEVA-FIT.sh). Official GitHub origin: https://github.com/Maufer58/KINEVA-FIT.git. Keep Mac ↔ GitHub aligned on the latest version and also update Privacy/EULA + landing on GitHub Pages. Details in README.md and ios/Signing/SIGNING.md.

To install on the paired Apple Watch: in the menu choose iPhone + Watch (not iPhone only). The watch must be unlocked, nearby, with Developer Mode enabled (Watch → Settings → Privacy & Security).

If the script says the iPhone is OK but the Watch is not (often tunnel=disconnected): iPhone → Watch app → My Watch → KINEVA FIT → Install. Then, if you still need the Mac tunnel: ./ios/scripts/install_iphone_watch.sh --watch-only --skip-git-sync.

If you see Developer Disk Image / CoreDevice 12040 / 0xe8000076 (“Could not support development” / “developer disk image could not be mounted”): this is not a KINEVA FIT build error. The iPhone is already installed; only the direct Mac→Watch install fails.

Why it “used to work” and now does not: Xcode / watchOS updates made mounting a matching Developer Disk Image (DDI) on the Watch over wireless mandatory. If Developer Mode is incomplete, the DDI does not match, or CoreDevice times out, Xcode rejects the install. The companion path (iPhone → Watch app → KINEVA FIT → Install) does not use the Mac DDI and remains the reliable route.

In order:
1. Watch → Settings → Privacy & Security → Developer Mode = ON, confirm the prompt, restart the watch.
2. Simplest path (no Mac DDI): iPhone → Watch app → KINEVA FIT → Install, then open KINEVA FIT on the Watch once.
3. If you still need a Mac install: align Xcode / watchOS support (Xcode → Settings → Platforms), then --watch-only. Do not retry the same command until you complete steps 1–2.
With ./fit.sh iPhone+Watch, if the DDI fails the script still leaves iPhone OK (exit 0) and points you to the companion path.

If iPhone/iPad install fails with CoreDevice error 1011 / DeviceIdentifier: ecid_*:
1. Unlock the device, screen on, USB cable, “Trust”, Developer Mode ON.
2. Check: xcrun xctrace list devices — the 00008… UDID must appear (not only ecid_…).
3. Then, without rebuilding: ENABLE_DEV_MENU=true PRODUCER_PASSWORD='MOVE2026' ./fit.sh --install-only.
The build may already be fine (SprayTuna/other devices installed): the error is only CoreDevice reachability.

If the Watch fails (tunnel=disconnected / Bluetooth timeout / DDI 12040): unlock the watch, Developer Mode ON (+ restart), keep it near the iPhone; or iPhone → Watch → KINEVA FIT → Install. Then ./ios/scripts/install_iphone_watch.sh --watch-only --skip-git-sync.

Apple “workouts on their own” on the Watch: KINEVA FIT sessions (after START) create a real HKWorkout in Fitness (source KINEVA FIT). It is not Apple’s Workout app starting by itself. Turn off Auto-start Workout in Watch → Workout if native Apple workouts start without KINEVA FIT. Calendar alerts only open the routine preview after a tap (they do not start HealthKit).

The KINEVA FIT complication does not appear on the face by itself: after opening KINEVA FIT on the Watch, long-press the face → Edit → choose KINEVA FIT. (KINEVA Intervals is a separate app: its complications appear only if you install that app.)

1. What KINEVA FIT is

KINEVA FIT is a workout and routine management app: you create or import workouts, run them on iPhone or Watch, keep history, and (on Pro plans) manage multiple athletes.

It is not a medical device. “Areas of attention” are training preferences, not diagnoses.

2. First launch

  1. Accept the Privacy Policy and EULA (required: open them and check “I have read”).
  2. Accept the training disclaimer.
  3. Complete onboarding (language, basic profile).
  4. (Optional) Start the trial or pick a plan from the paywall.

3. Home and routines

In the header, under the KINEVA FIT title, you see: plan · active user role (Athlete / Trainer · name / Supervisor) · Active client. The role is also at the top of the drawer (☰). Full paths: §14.

  • New routine: Home → New Routine → Manual editor, AI Wizard, import from photo, template library, free workout.
  • Groups: organize multiple routines under a group name.
  • Tap ▶ on a routine: opens the runner.
  • Routine menu (⋯): duplicate, archive, save as template (non-Free plans), schedule, Export Program, Send to Apple Watch (single routine, Athlete Pro+).

Export Program (PDF / image)

From the routine ⋯ menu → Export Program. First choose how to send it, then the format.

Channel (always, after choosing the format):

Channel What it does
Save file Visible copy on the device (Download / Documents). On Android/desktop you can pick the folder.
Email Opens share to attach the file; if the client has an email in their profile it is copied to the clipboard.
WhatsApp Opens share toward the chat.

The file is always saved locally: if Mail or WhatsApp do not open, the snackbar shows the path.

Formats:

Format Plan Content
Compact table (PDF) Athlete Pro+ More exercises per page: GIF, YouTube QR, sets/rest. Instructions and silhouettes after the table, with the same # number.
Illustrated table (PDF) Athlete Pro+ One row per exercise: Gym Visual GIF, YouTube QR (search “name + exercise”), muscle silhouettes, notes/description/execution beside the silhouette. Column header repeated on every page. No extra instruction appendix.
Program manual (PDF) Pro Plan / Studio Extended routine: GIF, silhouettes, tips and descriptions; same # numbering as the table.
HD image Pro Plan / Studio PNG ready for WhatsApp chat (same File / Email / WhatsApp picker).

Every PDF shows KINEVA FIT and the tagline Fitness & Workout Planner (studio logo if set in Settings). File names stay safe even if the routine title contains /. Circuits expand child exercises. If the profile has areas of attention, warnings stay visible on the row.

Manage mode (multi-select)

In the bar under the header (next to Expand groups / Show exercises) tap Manage:

  1. Select one or more routines (checkmark on the card) or an entire group.
  2. At the top, 「X Selected」 appears.
  3. Available actions:
    - ⌚ Send to Watch — sends all selected routines to the wrist (Athlete Pro+; see §7).
    - Select all — select/deselect the whole list.
    - Delete — removes selected routines and/or groups.
  4. Tap ✕ to leave Manage mode.

Note: with 2 or more routines the app uses a batch send (one transfer); if it fails, it automatically retries one routine at a time.

“on Watch” badge

After a successful send (Delivered or Queued), the card shows the on Watch badge.
If you delete the routine on the watch, the badge disappears on the iPhone too (automatic sync on launch if the Watch is reachable).

4. Athlete profile / clients

  • Enter profile details, optional measurements, sport.
  • Areas of attention: pick generic limitations (e.g. “knee discomfort”); the app flags poorly suited exercises and can hide them in selection (Athlete Pro+).
  • Free and Athlete Pro: a single personal profile (“Me (Default)”). You cannot create additional clients (drawer has no “New client”; paywall if attempted).
  • Pro Plan / Studio & Gym: trainer area with PIN, client drawer, duplicate, routine distribution (Pro: max 8 clients; Studio: unlimited; at the Pro limit an invite to Studio appears). Earlier Pro subscribers before the limit may keep unlimited clients (grandfathered).

Full trainer/gym operational manual: §13 below.

7. Apple Watch

Requirements: Athlete Pro plan (or active trial), KINEVA FIT installed on iPhone and Apple Watch, Bluetooth on, watch paired.

After installing KINEVA FIT on the Watch from the iPhone Watch app, open KINEVA FIT on the watch at least once before sending routines (so iPhone and Watch connect via WatchConnectivity).

Send a single routine

  1. From Home, ⋯ menu on the routine → Send to Apple Watch.
  2. Message: Delivered (Watch reachable) or Queued (open the Watch app to receive it).
  3. on Watch badge on the iPhone card.

Send multiple routines (batch)

  1. Home → toolbar → Manage.
  2. Select the routines (or an entire group).
  3. Tap the ⌚ icon at top right.
  4. Wait for the summary (e.g. “3 routines sent to Apple Watch”).

On the Watch

  1. Open the KINEVA FIT app on the watch.
  2. Tap routine → exercise preview → OPEN.
  3. On the runner: START (voice guide: exercise → 3-2-1 → Go).
  4. NEXT advances to the next set/exercise (or skips rest).
  5. During the exercise the next step appears at the bottom.
  6. Pause: single tap on the screen; Resume: double tap (the PAUSE badge does not cover the back button).
  7. Complication: KINEVA FIT only (HR/workout). If “KINEVA Intervals” still appears under FIT, it is leftover: delete and reinstall the Watch app (WATCH_COMPLICATIONS_ICONS.md).

iPhone ↔ Watch badge sync

On launch, if the Watch is reachable, the iPhone aligns on Watch badges with the routines actually present on the watch. Delete a routine on the Watch → the badge disappears on the iPhone too.

9. Calendar and history

  • Schedule recurring sessions.
  • Review volume, sessions, exercise detail.
  • PDF/image/JSON export on plans that allow it (see §13 for WhatsApp delivery and batch).
  • Branding in documents: PDF (compact/illustrated table, technical manual, encyclopedia), image export, and history reports always show the name KINEVA FIT, the tagline Fitness & Workout Planner, and the app logo; if in Settings (Trainer) you uploaded a studio logo, that replaces the KINEVA FIT icon in the header.
  • Personal cloud archive (Athlete Pro / Pro Plan / Studio): Settings → Base → Save history and charts (cloud) / Restore history from archive (also ZIP icon in History). Export: ZIP with JSON/CSV/PNG. Import: Merge or Replace from ZIP/history_full.json. Free plan: locked (paywall).

13. Trainer area, Studio & Gym (Pro Plan+)

Section for personal trainers, gyms, and studios. Requires Pro Plan or Studio & Gym (enableTrainerArea). On iPad the experience is optimal for routine catalogs and client delivery.

13.1 Access and security

  1. Settings → Trainer/Studio tools (card at the bottom of the Trainer Pro tab).
  2. If you lack the right plan → paywall.
  3. 4-digit PIN (required on Pro/Studio) after the first managed client: protects clients, database, and export. You can also enable Face ID / Touch ID. After inactivity or backgrounding the app asks for the PIN again. When you set the PIN you receive an 8-digit recovery code: keep it; if you forget the PIN you use it once to unlock (then set a new PIN). Disable only with PIN 0000 (not recommended if you manage third-party clients).
  4. Studio branding: business name, email, and logo — appear on PDF, encyclopedia, and export images.
  5. Routine sharing (JSON): selective export to other devices includes only the client id and name (not email, phone, conditions, or biometrics), plus the routines and custom exercises needed.

13.5 Exercise database and customization

Admin Panel → Exercises: search (standard vs custom), create/edit/delete.

  • New exercise: muscles, equipment, type, difficulty, notes, setup.
  • Per-exercise limitations: medical icon → conditions for which the exercise is not recommended.
  • Global limitations: Limitations — customizable catalog of conditions/motor limitations.
  • Muscles / equipment / types: Manage muscles, equipment, types — extend the master catalog.
  • Mobility protocols (Studio): Mobility protocols — rehab/mobility sequences assignable to clients.
  • Pilates Pack (Athlete+ add-on): mat + machine catalog (29 exercises) via New Routine → Pilates Pack. One-time purchase €9.99; not included in Studio or Pro Plan.

13.6 Profile ↔ exercise safety

  1. Set areas of attention / conditions in the client profile.
  2. In exercise selection enable “Hide unsuitable” (default): conflicting movements disappear from the list.
  3. In the runner session: area-of-attention banner if a borderline exercise remains.
  4. On PDF and export images: visual warnings for incompatibilities.
  5. Smart Swap: during the workout replace an exercise while staying on the same muscle group.

13.7 PDF encyclopedia (full manual)

Admin Panel → Export manuals (PDF) — same File / Email / WhatsApp channel as the routine:

  • Segments: Upper body · Lower · Core · Mobility · Full encyclopedia (entire database — long operation, needs plenty of RAM).
  • Each exercise sheet includes: Gym Visual GIF (first frame), YouTube QR (movement search), muscle silhouettes, description, execution, equipment, not recommended for.
  • The full catalog includes GIFs (they are no longer skipped).
  • Studio logo in the header; useful for reception and staff training.

14.3 Run a workout

  1. Home → ▶ on the routine → Runner (timer, rests, next, list).
  2. End of session → summary → save to History.
  3. Early exit: Delete and exit · Finish now · Suspend.
  4. Rerun / reset today: ⋯ on the routine → Rerun / Reset today’s run.

GPS run (Athlete Pro+): in the Editor use distance measure km → ▶ → GPS ON panel.
The track is saved in history (map) and, on iPhone, sent to Apple Fitness / Health at session end (workout + route).
Health consent (write only) is requested on first app launch and stays on by default. GPS asks for location only the first time you use it; later runs do not show the system sheets again. If it does not appear in Fitness: Settings → Health → Data Access → KINEVA FIT.
Free plan: cannot define or start distance exercises (paywall).
Privacy: More → Base → Save GPS route (on by default; if you turn it off, no map in history and no route in Fitness).
