3. Run a workout (Runner)

3.1 Classic start

Home → ▶ on the routine → Runner

  • Play / pause, next, exercise list
  • At end: summary → save to History

3.2 Early exit

Runner → (back / exit menu)

  • Delete and Exit
  • Finish Now (save partial)
  • Suspend Workout (resume later)

3.3 Rerun / reset today

Home → ⋯ on the routine → Rerun routine
Home → ⋯ → Restart (if suspended)
Home → ⋯ → Reset today’s run

3.4 Run / GPS distance

Paid plans only (Athlete Pro+). The Free plan cannot define or run distance / GPS exercises (editor, templates, import, runner).

  1. In Editor: exercise with distance (km) measure — Athlete Pro+
  2. Home → ▶ → during the session: GPS ON on the distance panel
  3. At workout end: map in History / summary + write to Apple Fitness / Health (iPhone)
  4. Privacy (default ON): More → Base → Save GPS route — if OFF, no coordinates in history and no route in Fitness

Apple Fitness note: workouts done on the Watch already go to Fitness via native HealthKit (Health and GPS consent once on first Watch use). iPhone-only runs (including free distance) are written to Health/Fitness at session end.
iPhone permission flow: (1) first launch → Health consent write only; (2) first GPS use → location consent; (3) at session end silent Fitness save if already authorized.
Watch permission flow: (1) first Watch app launch → Health read+write (HR/calories/live distance); (2) first outdoor GPS → When-In-Use location if not yet determined.
If you previously denied Health: iPhone Settings → Health → Data Access & Devices → KINEVA FIT → enable write.
Verify: Fitness app → Summary → scroll Workouts, or Health → Browse → Activity → Workouts.

5. Read history and progress

5.1 Session history

History (tab)
or Home → ☰ → History

  1. Open Filters (period: days/weeks/months/years; session type)
  2. On Pro/Studio: Filter Athlete
  3. Tap period → drill-down
  4. Tap session card → exercise / GPS / map detail
  5. Bulk export / cloud ZIP: icons in AppBar — Athlete Pro+

Cloud archive:

More → Base → MY DATA AND HISTORY → Save history and charts (cloud)
→ Restore history from archive → Merge / Replace

5.2 Stats / charts

Data (Stats tab)

  • Workout tab: volume, composition, performance, insight
  • Bio tab: biometric measures
  • Filter athlete (Pro/Studio)
  • Export: ⋮ → Export progress (PDF/JSON) — Athlete Pro+

6. Export routines (PDF / image / WhatsApp)

Home → ⋯ on the routine → Share / Export → Export Program

  1. Choose format
  2. Choose channel: Save file · Email · WhatsApp
Format Plan
Compact table (PDF) Athlete Pro+
Illustrated table (PDF) Athlete Pro+
Program manual (PDF) Pro Plan / Studio
HD image Pro Plan / Studio

The file is always saved locally even if sharing fails.

7. Apple Watch

Requirements: Athlete Pro+ (or trial), KINEVA FIT on iPhone and Watch, Bluetooth, watch paired.
After install from the iPhone Watch app: open KINEVA FIT on the Watch once before sending routines.

7.1 One routine

Home → ⋯ → Send to Apple Watch → on Watch badge

7.2 Multiple routines

Home → Manage → select → ⌚ at top

7.3 On the Watch

Open KINEVA FIT → tap routine → OPEN → START → NEXT
Pause: single tap · Resume: double tap

9. Multi-trainer / gym (Studio & Gym)

9.1 Login on launch

Lock overlay:

  1. Who is signing in? → choose Supervisor or Trainer (gear)
  2. Enter PIN on the on-screen keypad (not the system keyboard)
  3. Or 8-digit recovery code

The Home header shows the role (sec. 1.1).

9.2 Create a trainer (Supervisor only)

More → Trainer Pro → Studio tools → (PIN if required) → Admin
→ Trainer management → + / Add trainer

  1. Trainer name
  2. Trainer PIN (required for login)
  3. Enable access if needed

Max 3 trainers per device (+ 1 supervisor). Deleting a trainer does not free the seat immediately (30-day cooldown). Cleaning “ghost” seats is only in the producer menu (black door), not for the supervisor.

9.3 Activate / suspend a trainer

Trainer management → trainer card → Suspend / Reactivate
or bulk: Suspend or reactivate trainers

9.4 Share a client

☰ → ⋯ client → Share with trainers → choose owner and shares → close with X / CLOSE

9.5 Supervisor PIN

More → Trainer Pro → Protect with PIN / Change PIN
0000 = no PIN (only if there are no trainers that require protection)

12.3 Subscription / paywall

☰ Drawer → subscription banner
or More → banner at top
or lock on a Pro feature → paywall

On the paywall: Athlete / Pro Plan / Studio plans · monthly/yearly · 7-day trial (Store) · Restore purchases · Licensed devices if seats are full · Pilates Pack add-on card (€9.99 one-time) if the plan is Athlete Pro+.

13. Mobility / rehab (Studio & Gym)

Home → New Routine → Mobility Protocols
(first time: Mobility notice → Accept)

Catalog management:

More → Trainer Pro → Studio tools → Mobility Prot.

Assign protocols from the client profile (Edit profile → Mobility protocols).

Note: Studio mobility protocols and the Pilates Pack are distinct. Mobility is included in Studio; Pilates is a paid add-on for Athlete Pro+.

13bis. Pilates Pack (Athlete Pro+)

One-time add-on (€9.99): catalog of 29 Pilates exercises (mat + machine) with notes and silhouettes. Not included in Athlete, Pro Plan, or Studio.

Home → New Routine → Pilates Pack (item next to Mobility Protocols)

State What happens
Free plan Item shows “Available from Athlete Pro onwards”
Athlete+ without pack Opens in-app store / add-on paywall
Athlete+ with pack Opens exercise selection filtered “Pilates only” → editor

Purchase also from the paywall (add-on card under the plans). Product ID: com.mauroferrari.FITPlus.pilates — see REVENUECAT_APP_STORE_PRODUCTS.md §6bis.
