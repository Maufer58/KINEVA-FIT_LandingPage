3.4 Corsa / distanza GPS

Solo piani a pagamento (Athlete Pro+). Il piano Free non può definire né eseguire esercizi a distanza / GPS (editor, template, import, runner).

  1. In Editor: esercizio con misura distanza (km) — Athlete Pro+
  2. Home → ▶ → durante la sessione: GPS ON sul pannello distanza
  3. A fine workout: mappa nello Storico / riepilogo + scrittura su Apple Fitness / Salute (iPhone)
  4. Privacy (default ON): Altro → Base → Salva percorso GPS — se OFF, niente coordinate in storico né route in Fitness

Nota Apple Fitness: i workout fatti sul Watch vanno già in Fitness via HealthKit nativo (consenso Salute e GPS una sola volta al primo uso Watch). I run solo iPhone (anche distanza libera) vengono scritti in Salute/Fitness a fine sessione.
Flusso permessi iPhone: (1) primo avvio → consenso Salute in sola scrittura; (2) primo uso GPS → consenso posizione; (3) a fine sessione salvataggio Fitness silenzioso se già autorizzato.
Flusso permessi Watch: (1) primo avvio app Watch → Salute lettura+scrittura (FC/calorie/distanza live); (2) primo GPS outdoor → posizione When-In-Use se ancora non determinata.
Se in passato hai negato Salute: Impostazioni iPhone → Salute → Accesso dati e dispositivi → KINEVA FIT → attiva scrittura.
Verifica: app Fitness → Riepilogo → scorri Allenamenti, oppure Salute → Sfoglia → Attività → Allenamenti.

3.5 Nuoto

Runner: pannello vasche / stile / SWOLF (e lap Watch se disponibile).

7. Apple Watch

Requisiti: Athlete Pro+ (o trial), KINEVA FIT su iPhone e Watch, Bluetooth, orologio accoppiato.
Dopo install da app Watch dell’iPhone: apri KINEVA FIT sul Watch una volta prima di inviare schede.

7.1 Una scheda

Home → ⋯ → Invia ad Apple Watch → badge su Watch

7.2 Più schede

Home → Gestione → seleziona → ⌚ in alto

7.3 Sul Watch

Apri KINEVA FIT → tap scheda → APRI → INIZIA → AVANTI
Pausa: tap singolo · Riprendi: doppio tap

9. Multi-trainer / palestra (Studio & Gym)

9.1 Login all’avvio

Overlay blocco:

  1. Chi sta accedendo? → scegli Supervisore o Trainer (rotella)
  2. Digita PIN sul tastierino a schermo (non sulla tastiera di sistema)
  3. Oppure codice di recupero a 8 cifre

In testata Home compare il ruolo (sez. 1.1).

9.2 Creare un trainer (solo Supervisore)

Altro → Trainer Pro → Strumenti studio → (PIN se richiesto) → Admin
→ Gestione trainer → + / Aggiungi trainer

  1. Nome trainer
  2. PIN trainer (obbligatorio per il login)
  3. Abilita accesso se serve

Max 3 trainer per dispositivo (+ 1 supervisore). Eliminare un trainer non libera subito il posto (cooldown 30 giorni). La pulizia posti “fantasma” è solo nel menu produttore (black door), non per il supervisore.

9.3 Attivare / sospendere un trainer

Gestione trainer → scheda trainer → Sospendi / Riattiva
oppure bulk: Sospendi o riattiva trainer

9.4 Condividere un cliente

☰ → ⋯ cliente → Condividi con i trainer → scegli proprietario e condivisioni → chiudi con X / CHIUDI

9.5 PIN supervisore

Altro → Trainer Pro → Proteggi con PIN / Cambia PIN
0000 = nessun PIN (solo se non ci sono trainer che richiedono protezione)

13. Mobilità / rehab (Studio & Gym)

Home → Nuova Routine → Protocolli Mobilità
(prima volta: Informativa mobilità → Accetta)

Gestione catalogo:

Altro → Trainer Pro → Strumenti studio → Prot. Mobilità

Assegna protocolli dal profilo cliente (Modifica profilo → Protocolli mobilità).

Nota: i protocolli mobilità (Studio) e il Pacchetto Pilates sono distinti. La mobilità è inclusa in Studio; Pilates è un add-on a pagamento per Athlete Pro+.

13bis. Pacchetto Pilates (Athlete Pro+)

Add-on una tantum (9,99 €): catalogo 29 esercizi Pilates (mat + macchina) con note e silhouette. Non incluso in Athlete, Piano Pro né Studio.

Home → Nuova Routine → Pacchetto Pilates (voce accanto a Protocolli Mobilità)

Stato Cosa succede
Piano Free Voce indica «Disponibile da Athlete Pro in poi»
Athlete+ senza pack Apre lo store in-app / paywall add-on
Athlete+ con pack Apre la selezione esercizi filtrata «Solo Pilates» → editor

Acquisto anche dalla paywall (card add-on sotto i piani). Product ID: com.mauroferrari.FITPlus.pilates — vedi REVENUECAT_APP_STORE_PRODUCTS.md §6bis.
