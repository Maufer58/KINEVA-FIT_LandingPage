0. Installazione sviluppo (Mac)

Cartella progetto consigliata: KINEVA (non Stride / MOVEFitness). Lo stesso script rinomina anche Stride_Policy → KINEVA-FIT_Policy, Stride_LandingPage → KINEVA-FIT_LandingPage e Stride_Backups → KINEVA-FIT_Backups in ~/Documents: ./tool/rename_mac_project_dir.sh.

Build device/simulatore: ./fit.sh (oppure ./KINEVA-FIT.sh). Origin GitHub ufficiale: https://github.com/Maufer58/KINEVA-FIT.git. Allinea Mac ↔ GitHub sulla versione più recente e aggiorna anche Privacy/EULA + landing su GitHub Pages. Dettagli in README.md e ios/Signing/SIGNING.md.

Per installare sull’Apple Watch abbinato: nel menu scegli iPhone + Watch (non solo iPhone). L’orologio deve essere sbloccato, vicino, con Modalità sviluppatore attiva (Watch → Impostazioni → Privacy e sicurezza).

Se lo script dice che iPhone è OK ma il Watch no (spesso tunnel=disconnected): iPhone → app Watch → Il mio orologio → KINEVA FIT → Installa. Poi, se serve ancora il tunnel Mac: ./ios/scripts/install_iphone_watch.sh --watch-only --skip-git-sync.

Se compare Developer Disk Image / CoreDevice 12040 / 0xe8000076 («Could not support development» / «developer disk image could not be mounted»): non è un errore di build KINEVA FIT. iPhone è già installato; fallisce solo l’install diretta Mac→Watch.

Perché “prima funzionava” e ora no: aggiornamenti di Xcode / watchOS hanno reso obbligatorio montare un Developer Disk Image (DDI) allineato sulla Watch via wireless. Se Modalità sviluppatore non è completa, il DDI non corrisponde, o CoreDevice va in timeout, Xcode rifiuta l’install. La via companion (iPhone → app Watch → KINEVA FIT → Installa) non usa il DDI Mac e resta quella affidabile.

In ordine:
1. Watch → Impostazioni → Privacy e sicurezza → Modalità sviluppatore = ON, conferma l’avviso, riavvia l’orologio.
2. Via più semplice (senza DDI Mac): iPhone → app Watch → KINEVA FIT → Installa, poi apri KINEVA FIT sul Watch una volta.
3. Se serve ancora install da Mac: allinea Xcode / supporto watchOS (Xcode → Settings → Platforms), poi --watch-only. Non ritentare lo stesso comando finché non fai i passi 1–2.
Con ./fit.sh iPhone+Watch, se il DDI fallisce lo script lascia comunque iPhone OK (exit 0) e indica il companion.

Se l’install iPhone/iPad fallisce con CoreDevice error 1011 / DeviceIdentifier: ecid_*:
1. Sblocca il device, schermo acceso, cavo USB, «Attendibile», Modalità sviluppatore ON.
2. Verifica: xcrun xctrace list devices — deve comparire l’UDID 00008… (non solo ecid_…).
3. Poi, senza ricompilare: ENABLE_DEV_MENU=true PRODUCER_PASSWORD='MOVE2026' ./fit.sh --install-only.
La build può essere già OK (SprayTuna/altri device installati): l’errore è solo di raggiungibilità CoreDevice.

Se il Watch fallisce (tunnel=disconnected / Bluetooth timeout / DDI 12040): sblocca l’orologio, Modalità sviluppatore ON (+ riavvio), vicino all’iPhone; oppure iPhone → Watch → KINEVA FIT → Installa. Poi ./ios/scripts/install_iphone_watch.sh --watch-only --skip-git-sync.

Allenamenti Apple “da soli” sul Watch: le sessioni KINEVA FIT (dopo INIZIA) creano un vero HKWorkout in Fitness (sorgente KINEVA FIT). Non è l’app Allenamento di Apple che parte da sola. Disattiva Rilevamento automatico allenamento in Watch → Allenamento se i workout Apple nativi partono senza KINEVA FIT. Gli avvisi calendario aprono solo l’anteprima scheda dopo un tap (non avviano HealthKit).

La complicazione KINEVA FIT non compare da sola sul quadrante: dopo aver aperto KINEVA FIT sul Watch, long-press sul quadrante → Modifica → scegli KINEVA FIT. (KINEVA Intervals è un’app separata: le sue complicazioni compaiono solo se installi quell’app.)

1. Cos’è KINEVA FIT

KINEVA FIT è un’app di allenamento e gestione schede: crei o importi workout, li esegui su iPhone o Watch, tieni lo storico e (nei piani Pro) gestisci più atleti.

Non è un dispositivo medico. Le “aree di attenzione” sono preferenze di allenamento, non diagnosi.

2. Primo avvio

  1. Accetta Privacy Policy e EULA (obbligatorio: aprili e spunta “preso visione”).
  2. Accetta il disclaimer di allenamento.
  3. Completa l’onboarding (lingua, profilo base).
  4. (Opzionale) Avvia il trial o scegli un piano dalla paywall.

3. Home e schede

In testata, sotto il titolo KINEVA FIT, vedi: piano · ruolo utente attivo (Atleta / Trainer · nome / Supervisore) · Cliente attivo. Il ruolo è anche in cima al drawer (☰). Percorsi completi: §14.

  • Nuova scheda: Home → Nuova Routine → Editor manuale, AI Wizard, import da foto, libreria template, allenamento libero.
  • Gruppi: organizza più schede sotto un nome gruppo.
  • Tap ▶ su scheda: apre il runner.
  • Menu scheda (⋯): duplica, archivia, salva come template (piani non Free), pianifica, Esporta programma, Invia su Apple Watch (singola scheda, Athlete Pro+).

Modalità Gestione (multi-selezione)

Nella barra sotto l’header (accanto a Espandi gruppi / Visualizza esercizi) tocca Gestione:

  1. Seleziona una o più schede (spunta sulla card) oppure un intero gruppo.
  2. In alto compare 「X Selezionati」.
  3. Azioni disponibili:
    - ⌚ Invia su Watch — invia tutte le schede selezionate al polso (Athlete Pro+; vedi §7).
    - Seleziona tutto — seleziona/deseleziona l’intera lista.
    - Elimina — cancella schede e/o gruppi selezionati.
  4. Tocca ✕ per uscire dalla modalità Gestione.

Nota: con 2 o più schede l’app usa un invio batch (un solo transfer); se fallisce, riprova una scheda alla volta in automatico.

Badge «su Watch»

Dopo un invio riuscito (Consegnata o In coda), la card mostra il badge su Watch.
Se elimini la scheda sull’orologio, il badge scompare anche sull’iPhone (sync automatica all’avvio se il Watch è raggiungibile).

4. Profilo atleta / clienti

  • Inserisci anagrafica, misure opzionali, sport.
  • Aree di attenzione: scegli limitazioni generiche (es. “fastidio ginocchio”); l’app segnala esercizi poco adatti e può nasconderli in selezione (Athlete Pro+).
  • Free e Athlete Pro: un solo profilo personale («Io (Default)»). Non è possibile creare clienti aggiuntivi (drawer senza «Nuovo cliente»; paywall se si tenta).
  • Piano Pro / Studio & Gym: area trainer con PIN, drawer clienti, duplica, distribuzione schede (Pro: max 8 clienti; Studio: illimitati; al limite Pro compare invito a Studio). Abbonati Pro precedenti al limite possono conservare clienti illimitati (grandfather).

7. Apple Watch

Requisiti: piano Athlete Pro (o trial attivo), app KINEVA FIT installata su iPhone e su Apple Watch, Bluetooth attivo, orologio accoppiato.

Dopo aver installato KINEVA FIT sul Watch dall’app Watch dell’iPhone, apri KINEVA FIT sull’orologio almeno una volta prima di inviare schede (così iPhone e Watch si collegano via WatchConnectivity).

Invio singola scheda

  1. Dalla Home, menu ⋯ sulla scheda → Invia su Apple Watch.
  2. Messaggio: Consegnata (Watch raggiungibile) o In coda (apri l’app Watch per riceverla).
  3. Badge su Watch sulla card iPhone.

Invio di più schede (batch)

  1. Home → barra strumenti → Gestione.
  2. Seleziona le schede (o un gruppo intero).
  3. Tocca l’icona ⌚ in alto a destra.
  4. Attendi il riepilogo (es. «3 schede inviate su Apple Watch»).

Sul Watch

  1. Apri l’app KINEVA FIT sull’orologio.
  2. Tap scheda → anteprima esercizi → APRI.
  3. Sul runner: INIZIA (voce guida: esercizio → 3-2-1 → Via).
  4. AVANTI passa al set/esercizio successivo (o salta il recupero).
  5. Durante l’esercizio compare il prossimo step in basso.
  6. Pausa: tap singolo sullo schermo; Riprendi: doppio tap (il badge PAUSA non copre il pulsante indietro).
  7. Complication: solo KINEVA FIT (HR/workout). Se compare ancora “KINEVA Intervals” sotto FIT, è un residuo: elimina e reinstalla l’app Watch (WATCH_COMPLICATIONS_ICONS.md).

Sync badge iPhone ↔ Watch

All’avvio, se il Watch è raggiungibile, l’iPhone allinea i badge su Watch con le schede realmente presenti sull’orologio. Elimina una scheda sul Watch → il badge sparisce anche sull’iPhone.

13. Area Trainer, Studio & Gym (Piano Pro+)

Sezione dedicata a personal trainer, palestre e studi. Richiede Piano Pro o Studio & Gym (enableTrainerArea). Su iPad l’esperienza è ottimale per catalogo schede e consegna clienti.

13.1 Accesso e sicurezza

  1. Impostazioni → Strumenti Trainer/Studio (card in fondo al tab Trainer Pro).
  2. Se non hai il piano adatto → paywall.
  3. PIN a 4 cifre (obbligatorio su Pro/Studio) dopo il primo cliente gestito: protegge clienti, database e export. Puoi abilitare anche Face ID / Touch ID. Dopo inattività o messa in background l’app richiede di nuovo il PIN. All’impostazione del PIN ricevi un codice di recupero a 8 cifre: conservalo; se dimentichi il PIN lo usi una volta per sbloccare (poi imposti un PIN nuovo). Disattiva solo con PIN 0000 (sconsigliato se gestisci clienti terzi).
  4. Branding studio: nome attività, email e logo — compaiono su PDF, enciclopedia e immagini export.
  5. Condivisione schede (JSON): l’export selettivo verso altri dispositivi include solo id e nome del cliente (non email, telefono, patologie o biometria), più le schede e gli esercizi custom necessari.

13.5 Database esercizi e personalizzazione

Admin Panel → Esercizi: cerca (standard vs custom), crea/modifica/elimina.

  • Nuovo esercizio: muscoli, attrezzo, tipologia, difficoltà, note, setup.
  • Limitazioni per esercizio: icona medica → condizioni per cui l’esercizio è sconsigliato.
  • Limitazioni globali: Limitazioni — catalogo patologie/limitazioni motorie personalizzabile.
  • Muscoli / attrezzatura / tipi: Gestione muscoli, attrezzatura, tipi — estendi il catalogo master.
  • Protocolli mobilità (Studio): Protocolli mobilità — sequenze riabilitazione/mobilità assegnabili ai clienti.
  • Pacchetto Pilates (add-on Athlete+): catalogo mat + macchina (29 esercizi) via Nuova Routine → Pacchetto Pilates. Acquisto una tantum 9,99 €; non incluso in Studio né Piano Pro.

13.6 Sicurezza profilo ↔ esercizi

  1. Imposta aree di attenzione / patologie nel profilo cliente.
  2. In selezione esercizi attiva «Nascondi inadatti» (default): movimenti in conflitto spariscono dalla lista.
  3. In sessione runner: banner area di attenzione se resta un esercizio borderline.
  4. Su PDF e immagini export: avvisi visivi sulle incompatibilità.
  5. Smart Swap: durante l’allenamento sostituisci un esercizio restando sullo stesso gruppo muscolare.

13.7 Enciclopedia PDF (manuale intero)

Admin Panel → Esporta manuali (PDF) — stesso canale File / Email / WhatsApp della scheda:

  • Segmenti: Upper body · Lower · Core · Mobilità · Enciclopedia completa (intero database — operazione lunga, richiede molta RAM).
  • Ogni scheda esercizio include: GIF Gym Visual (primo frame), QR YouTube (ricerca del movimento), silhouette muscolari, descrizione, esecuzione, attrezzatura, sconsigliato per.
  • Il catalogo completo include le GIF (non vengono più saltate).
  • Logo studio in intestazione; utile per reception e formazione staff.

14. Guida operativa — percorsi di menu (tutte le funzioni)

14.2 Creare una scheda

Metodo Voce menu Piano

Trasferisci esercizi: Home → Trasferisci → seleziona → COPIA o SPOSTA.

14.3 Eseguire un allenamento (run)

  1. Home → ▶ sulla scheda → Runner (timer, recuperi, avanti, lista).
  2. Fine sessione → riepilogo → salvataggio in Storico.
  3. Uscita anticipata: Elimina e esci · Concludi ora · Sospendi.
  4. Riesegui / azzera oggi: ⋯ sulla scheda → Riesegui / Azzera esecuzione di oggi.

Corsa GPS (Athlete Pro+): in Editor usa misura distanza km → ▶ → pannello GPS ON.
La traccia viene salvata nello storico (mappa geografica) e, su iPhone, inviata ad Apple Fitness / Salute a fine sessione (workout + percorso).
Il consenso Salute (sola scrittura) viene chiesto al primo avvio dell’app e resta attivo come default. Il GPS chiede la posizione solo la prima volta che lo usi; le corse successive non ripropongono i fogli di sistema. Se non compare in Fitness: Impostazioni → Salute → Accesso dati → KINEVA FIT.
Piano Free: non può definire né avviare esercizi a distanza (paywall).
Privacy: Altro → Base → Salva percorso GPS (attivo di default; se disattivi, niente mappa nello storico né route in Fitness).

14.9 Creare e gestire trainer (Studio & Gym · Supervisore)

  1. Altro → Trainer Pro → Strumenti studio → (PIN) → Admin
  2. Gestione trainer → + / Aggiungi trainer → nome + PIN → salva
  3. Abilita login, Sospendi/Riattiva, Esporta, Elimina (posto licenza con cooldown 30 gg)
  4. Login: overlay → scegli profilo (rotella) → PIN sul tastierino a schermo

Max 3 trainer/dispositivo + supervisore. La liberazione posti “fantasma” non è nel menu supervisore (solo black door produttore).
